# API Fundamentals

## Objective

Understand how APIs work from a QA Engineer's perspective before using Postman.

## Topics Covered

- What is an API?
- Client-Server Architecture.
- API Request and Response.
- Why API Testing is important.
- API Testing vs UI Testing.
- Introduction to JSON.

## QA Understanding

An API is the communication bridge between a client application (Mobile/Web) and the backend server.

## Real Project Example (Getkart)

- Login API
- Registration API
- Wallet API
- Ads API
- Banner API
- Likes API
- Order History API

## Key Learnings

- Client sends Request.
- Server processes Request.
- Database stores data.
- Server sends Response.
- QA validates Response and Database.

## Interview Notes

API testing validates backend business logic directly and is faster than UI testing for many validation scenarios.
